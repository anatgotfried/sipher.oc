Agent Cards

Terms

Last updated: May 12, 2026

Self-hosted software

Agent Cards is provided as local-first software for creating, viewing, and responding to structured cards from AI agents and automation scripts.

Human control

Agents should use cards for reviewable decisions, approvals, questions, status updates, and preference feedback. Do not use the default local server as a public approval system without adding production-grade security controls.

Callbacks and automations

You are responsible for the agents, scripts, callback URLs, and automations you connect to Agent Cards.
